🏰 Kingdom Focus

Turn your focus time into an epic kingdom-building adventure!

⚡ Quick Start

1. Start the Backend Server
cd backend
npm install
npm run dev

✅ Server will run on http://localhost:3000

2. Play the Game
http://localhost:3000

✅ Web interface will load automatically

📋 Prerequisites

Required:
  • Node.js 18+ (Download)
  • PostgreSQL 14+ (Download)
  • Git (Download)

🛠️ Setup Instructions

Step 1: Clone Repository
git clone https://github.com/Brodiezz/kingdom-focus.git
cd kingdom-focus
Step 2: Setup Database
psql -U postgres
CREATE DATABASE kingdom_focus;
\c kingdom_focus
\i backend/src/db/schema.sql
\q
Step 3: Configure Backend
cd backend
cp .env.example .env

Edit .env with your database credentials:

DB_HOST=localhost
DB_PORT=5432
DB_NAME=kingdom_focus
DB_USER=postgres
DB_PASSWORD=your_password

JWT_SECRET=your_secret_key
NODE_ENV=development
PORT=3000
Step 4: Install & Run Backend
npm install
npm run dev

✅ You should see: "🏰 Kingdom Focus API Server"

Step 5: Access the Game

Open your browser and go to:

http://localhost:3000

✅ You're ready to play!

🎮 How to Play

1. Create Account

Click "Create Account" and set up your kingdom and hero name

2. Schedule a Quest

Enter your focus task name and duration (15-240 minutes)

Select difficulty: Easy, Medium, Hard, or Legendary

3. Start Quest

Click "Start Quest" and focus during the timed session

The timer will count down in real-time

4. Complete Quest

When done, click "Complete Quest"

Earn Gold, XP, and maintain your focus streak!

5. Build Kingdom

Use earned gold to construct medieval buildings

Each building generates passive income

Higher level buildings earn more gold per hour!

6. Check Leaderboards

See how you rank against other focused players

Compete globally or with guild members

🔧 Troubleshooting

Database Connection Error
psql -U postgres -d kingdom_focus

Make sure PostgreSQL is running and credentials match .env

Port 3000 Already in Use
PORT=3001 npm run dev

Or stop whatever is using port 3000

CORS Errors

Make sure backend is running on http://localhost:3000

Clear browser cache and reload

Can't Connect to API
curl http://localhost:3000/health

If this fails, backend isn't running
